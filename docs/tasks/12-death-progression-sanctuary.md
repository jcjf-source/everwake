# Task 12 — Expedition ending, death, upgrades, and sanctuary

## Objective
Create the repeatable expedition loop with permanent progression.

## Scope
- Implement voluntary return and death as expedition-ending outcomes.
- Show summary: distance, tiles discovered, gathered resources, enemies, POIs, turns/time, cause/end reason.
- On death, lose carried expedition loot according to design; retain world seed, explored map, discoveries, permanent upgrades, and persistent changes.
- Award permanent progression currency based on exploration/discovery.
- Sanctuary is a safe respawn/start location.
- Implement at least three functional upgrades: Survivor, Cartographer, Pathfinder, Scavenger (choose three or more).
- Allow spending currency and show upgrade effects.
- Starting a new expedition resets temporary expedition state but not world or permanent state.

## Acceptance
Player can complete multiple expeditions; death returns to sanctuary and report screen; world and knowledge remain; upgrades are purchasable and affect gameplay; carried loot loss/voluntary return rules are clear and tested.
