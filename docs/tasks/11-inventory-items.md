# Task 11 — Inventory, equipment, and consumables

## Objective
Provide a functional inventory for expedition supplies and rewards.

## Scope
- Implement inventory quantities, item definitions, equipment slots for basic weapon/armor, and use actions.
- Items: starter weapon/armor, healing potion, food, wood, stone, herbs, gathered food, and loot.
- Consumables change player state and cost turns where appropriate.
- Gathering, combat rewards, chest rewards, and inventory UI use the same inventory source of truth.
- Drag/drop is not required; simple buttons are acceptable.

## Acceptance
Items are added, removed, used, and equipped correctly; quantities and stats update; invalid item actions are rejected without consuming turns; inventory works on narrow screens.
