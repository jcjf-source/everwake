# Task 14 — UI, mobile usability, and visual polish

## Objective
Polish the playable prototype without changing game rules unnecessarily.

## Scope
- Review UI hierarchy, contrast, typography, map focus, panels, event log, contextual controls, and responsive behavior.
- Make controls and touch targets comfortable on mobile.
- Improve terrain and entity visual distinction; reduce repetitive patterns.
- Add helpful feedback for selection, path preview, action success/failure, damage, discoveries, and save status.
- Add keyboard focus and accessible labels for HTML controls where applicable.
- Ensure panel interactions do not unintentionally trigger map actions.

## Acceptance
The game is legible and usable at desktop and mobile sizes; map remains the focal point; all controls are functional; input does not conflict; no visual polish regresses game behavior. Document manual viewport checks.
