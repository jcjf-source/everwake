# Task 00 — Project setup and runnable shell

## Objective
Create the smallest clean project scaffold that launches in a browser and can be hosted on GitHub Pages.

## Read first
Read `docs/GAME_DESIGN.md`, `docs/ROADMAP.md`, `docs/TECHNICAL.md`, `docs/AI_RULES.md`.

## Scope
- Inspect the repository and preserve existing work.
- Create a minimal app entry point, stylesheet, and source structure suitable for plain JavaScript and Canvas.
- Add a full-screen game shell with an atmospheric placeholder scene, title/working title, and responsive layout.
- Add a README with local run and GitHub Pages instructions appropriate to the chosen setup.
- Add basic error reporting that does not hide failures.

## Out of scope
Hex grid, world generation, movement, gameplay systems.

## Acceptance
Browser launches without console errors; layout works at desktop and mobile viewport sizes; project can be run and deployed using documented steps. No buttons may be inert—omit controls not yet implemented.
