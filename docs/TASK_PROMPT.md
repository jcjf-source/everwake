# Reusable prompt for each coding task

You are developing EVERWAKE. Read `docs/GAME_DESIGN.md`, `docs/ROADMAP.md`, `docs/TECHNICAL.md`, `docs/AI_RULES.md`, and the selected task file before changing code.


Treat these documents as the project's source of truth. Inspect existing files first. Implement ONLY the selected task and essential dependencies. Do not start future tasks, redesign existing systems, remove working features, or add major dependencies without discussing it first. Keep the game runnable, modular, mobile-friendly, and consistent with the established architecture. Implement real behavior, not mockups. Test the result and do not claim checks were run if they were not.


When finished, update documentation as appropriate and report: changes made; files modified; tests/checks actually run; manual verification steps; limitations; and confirmation that you stopped without starting the next task.
