# Everwake documentation pack

Copy this `docs` folder into the root of your game repository. Read `GAME_DESIGN.md` for the vision, `ROADMAP.md` for milestones, and `AI_RULES.md` before asking a coding agent to work. Execute one task file at a time.


## Suggested workflow
1. Start with `tasks/00-project-setup.md`.
2. Give your coding agent the standard task instruction (see `TASK_PROMPT.md`) and the chosen task file.
3. Review and play-test its result.
4. Continue only after acceptance criteria pass.
